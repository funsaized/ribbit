## Offline factual regrade (rubric 2.0.0)

No provider, executable build, credentials, or inference is needed:

```sh
bun run eval:regrade -- evals/results/workflows/2026-10-03T17-34-01-189Z/report.json --output workflow-regrade.json
```

The command accepts command/workflow reports with `schemaVersion: 1` or `2`, including the version-2 handoff report. It writes a new derived record, leaves the source untouched, and refuses to overwrite an existing output. Omit `--output` to print JSON. Exit zero means replay completed, not factual acceptance; inspect `status` and criterion verdicts. Unknown cases and unreviewed prose are `review_required`. A missing final run verdict leaves completion `unknown`.

Each attempt separates shape, invariant, fact, citation, and review results, with expected/actual values and diagnostics. The replay pins the source-report, grader/replay implementation, fixtures, case, output, and optional review hashes. Character spans use JavaScript string offsets into original stdout. Raw transcripts remain in the source artifact; derived previews are bounded. Unknown tokens/cost and unmeasured selection recall are not inferred.

Prose facts are relations such as owner/action, by/on deadline, amount/currency, file/limit comparison, ownership/count, purchase behavior, and session-validity truth conditions. Keyword presence cannot certify them. An exact authored reference can pass deterministically. Other prose requires explicit output-bound source review.

There are **no default reviews**. Supply `--reviews YOUR_REVIEWS.json` with this shape:

```json
{
  "schemaVersion": 1,
  "rubricVersion": "2.0.0",
  "entries": [{
    "id": "summarize-facts",
    "caseSha256": "COPY_FROM_DERIVED_ATTEMPT",
    "outputSha256": "COPY_FROM_DERIVED_ATTEMPT",
    "reviewer": {"kind": "human", "name": "ACTUAL_REVIEWER"},
    "judgments": [{
      "criterion": "deadline",
      "actual": {"relation": "by", "day": "Friday"},
      "quote": "EXACT_SUPPORTING_SPAN_FROM_STDOUT",
      "reason": "Explain how the source and output support this relation."
    }]
  }]
}
```

Fill every applicable fact/citation judgment, including `unsupported`; missing judgments stay unknown. Read the complete source and output. Quotes must resolve exactly, and duplicate judgments/reviews are rejected. Changed outputs, fixtures, or rubric versions cannot reuse stale reviews. Reviewer identity/kind is an attestation, not authenticated identity. Keep AI reviews labeled `ai`; they do not satisfy independent human review.

Run `bun test tests/evals` for synthetic replay, contradiction, quote-binding, and source-preservation checks.

## Reproduce

Load the existing models locally, then run:

```sh
bun run build
RIBBIT_RUN_LIVE_EVAL=1 bun run eval:release -- --model YOUR_INSTALLED_MODEL --profile evaluation --mode full --quantization Q4_K_M --max-output-tokens 2048
RIBBIT_RUN_LIVE_EVAL=1 bun run eval:workflows -- YOUR_SMALL_MODEL YOUR_STRONGER_MODEL
RIBBIT_RUN_LIVE_EVAL=1 bun run eval:handoff -- YOUR_LOCAL_MODEL
```

The command runner accepts only a credential-free loopback URL and freezes the executable at run start. `--mode smoke` runs each selected case once; `full` repeats three times. Use `--command NAME` to narrow the run. Reports record build/source/lock and evaluator hashes, dirty-tree status, fixtures, model/configuration, stdout/stderr, statistics, wall time, and every command HTTP request/response. The proxy buffers SSE, so wall time includes recording and CLI overhead. `pick` requires Python 3 and fzf.

All runners use schema version 2 and rubric 2.0.0. Every required criterion must pass every repetition; pending review blocks acceptance. Initial-call validity is separate from factual correctness. A completed run can exit nonzero because it contains failures or pending reviews.

Workflows use two models already loaded in local LM Studio. They record every CLI stage's input, output, errors, statistics, and total wall time for local-only, direct-stronger, and mixed routes. Triage/context check original values, IDs, sources, and fixture bytes. Neither workflow semantically filters evidence, so selection false negatives remain `null`. Downstream bytes are evidence size, not billed tokens.

The handoff invokes the installed Codex CLI with an isolated CODEX_HOME, no user configuration, an explicit local provider, read-only sandbox, and a 120-second bound. It records the context and raw harness events and applies the context rubric instead of certifying answers by source-name presence. It tests one interpretation task, not autonomous coding. Command runs request temperature 0 and reasoning off; workflow reasoning and harness sampling use defaults. Cache state and unrelated workstation load are uncontrolled.

Keep only the latest completed run per configuration, including failed attempts, and update the manifest and documentation together. Do not change fixtures, prompts, or thresholds to fit observed answers. `bun run scripts/release/docs.ts` renders command examples from the catalog. See the [release checklist](../docs/release-checklist.md).
